# humanizer

Humanizer 是一个 Agent Skill,用于将带有 AI 写作痕迹的文本改写为更像真人书写,同时保留原意。它基于维基百科的 AI 写作特征清单,定义了 25 种模式,并在改写时避免编造事实。

## 适用人群

- 需要去除 AI 痕迹的写作者、内容创作者、编辑

## 主要能力

- 在不改变语义的前提下改写 AI 生成的文本,使其读起来更像真人写作

## 使用说明

- 这些改写模式针对 AI 生成文本,若在改写过程中引入事实性错误,需要依赖其“不编造”原则,但具体机制需人工验证。
